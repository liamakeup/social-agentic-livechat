    Mô hình & Fallback

    Fallback chỉ hoạt động khi có đủ Base URL + Model + API key; nếu thiếu, mọi chiến lược đều chạy như cf-only.

    Để trống ô API key = giữ nguyên key đã lưu. Key được mã hoá trong D1 và không bao giờ hiển thị lại.

    Remote MCP server

    "call_tool" cho Zernio; để trống nếu server lộ tool trực tiếp.

    Để trống ô token = giữ nguyên token đã lưu. Đổi URL sang máy chủ (host) khác hoặc xoá URL mà không nhập token mới thì token đã lưu sẽ bị xoá, để token không bị gửi tới máy chủ lạ.
